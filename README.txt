Eleven 7 - build steps
1. Create a new GitHub repo and upload ALL files from this folder (keep the hidden .github folder).
2. Open the Actions tab > "Build APK" > wait for the green tick (about 3-5 minutes).
3. Open that run > Artifacts > download "Eleven7-apk", unzip it, install app-debug.apk.
4. First launch: tap Allow, then turn on "Allow access to manage all files".
5. Your pages live in the Eleven7 folder in internal storage. Use + to add HTML files, or copy files there with a file manager and tap Refresh.
